# guitar_tool

A guitar-first music theory and transposition app. It will help players identify song keys, compare capo options, transpose chord progressions, and learn notes across the fretboard.

## Initial direction

- Enter or import a song's chord progression
- Detect its likely concert key
- Rank easier chord shapes and capo positions while preserving the original pitch
- Transpose into a different concert key when desired
- Visualize notes, scales, and chords on an interactive guitar fretboard
- Save songs and practice progress across desktop and mobile
